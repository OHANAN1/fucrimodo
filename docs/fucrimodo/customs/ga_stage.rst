========
GA Stage
========

The class :class:`GeneticAlgorithm` implements a fully functioning genetic
algorithm.  To interface with the :class:`MultiStageSearch` the class
:class:`GAStage` implements a wrapper to handle data storage, statistics
tracking and logging.
