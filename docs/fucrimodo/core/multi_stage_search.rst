==================
Multi stage search
==================

.. currentmodule:: fucrimodo.core.multi_stage_search

This is the main class needed to run a Multi Stage Search. The most important
method for the user is :meth:`MultiStageSearch.run`. With it the stages can be
performed.  For examples how to perform a multi stage search look at the
tutorial :ref:`fucrimodo_as_library`.
