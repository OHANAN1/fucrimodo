==================
Global SOAP target
==================

.. currentmodule:: fucrimodo.customs.global_soap_target

The :class:`GlobalSOAP` is implemented to consistently calculate feature vectors for runs where the target features are expected to be a global soap descriptor. Global SOAP descriptor means that the local descriptors are averaged. More information can be found in the original `SOAP paper <https://doi.org/10.1103/PhysRevB.87.184115>`__ or in the `DScribe documentation <https://singroup.github.io/dscribe/latest/tutorials/descriptors/soap.html>`__.
