**FUCrIMODo** is a program that aims to retrieve the crystal structure from
a SOAP descriptor. 
This is done with the help of a novel *multi-stage* Genetic Algorithm (GA).

## Usage

INCOMPLETE

To retrieve the desired cartesian coordinates of a given SOAP descriptor 
replace `target_crystal` or `target_soap_features` in fucrimodo/__main__.py
Then in the commanline run

```bash
python fucrimodo
```
